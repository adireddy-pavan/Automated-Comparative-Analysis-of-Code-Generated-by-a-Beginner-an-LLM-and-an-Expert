# Blank reviewer protocol — NOT COMPLETED

This form is an instruction for an independent reviewer, not evidence that one was recruited. Do not backdate or prefill a reviewer's judgement.

Reviewers should NOT be shown the constructed labels of sample files when evaluating perceived difficulty or expertise. To minimize confirmation bias, rename/counterbalance files and randomize the presentation order *before* review; retain a key separately. Disclose whether reviewers previously saw the solutions and register the assessment dates honestly.

For each of the 30 tasks record: task ID; expected difficulty (introductory/intermediate/advanced); reviewer difficulty rating (1–5); task-specification clarity (1–5); boundary-case sufficiency (1–5); source-file code-style rating (1–5), reviewer uncertainty; supporting comments. Capture reviewer experience/consent as appropriate under institution policy.

Acceptance criteria must be written **before** using the ratings to change the benchmark. Do not replace observations with selected favourable ratings or claim these reference solutions were collected from real novices/experts.
