# LLM Solution Provenance

This file records how the **LLM** arm of the benchmark was produced, to record author-reported generation details. It does not independently authenticate
provider identity, sampling independence, or original generation settings. It complements (does not replace) the determinism of the
analysis pipeline: once these solution files are committed, every run of
`run_analysis.py` analyses the stored same code bytes, subject to tool-version and environment changes. Only the
*generation* below involves a model.

## Model

| Field | Value |
|---|---|
| Model family | Claude (Anthropic) |
| Model | Claude Opus 4.8 (`claude-opus-4-8`) |
| Access | Generated by the model directly within the Claude Code agent harness |
| Date generated | 2026-06-25 |
| Decoding | Author-reported default assistant decoding; independent generations NOT verified |
| Samples per task (k) | 5 (`config.SAMPLES_PER_SOURCE["llm"]`) |
| Language constraint | Python standard library only |

> **Single model family.** All LLM solutions come from one current model family
> (Claude). The proposal's ideal of a second, GPT-4-class model is recorded as a
> known limitation and left as future work; the framework already supports it —
> additional samples only need to be added under each task's `solutions/llm/`.

## Layout

For every task, five independent LLM samples are stored at:

```
dataset/tasks/<task_id>/solutions/llm/sample_1.py
dataset/tasks/<task_id>/solutions/llm/sample_2.py
...
dataset/tasks/<task_id>/solutions/llm/sample_5.py
```

The archived files implement the task entry point. Their generation history and sampling independence have not been verified. The samples vary (algorithm, structure, idiom, verbosity) so that
within-source variance is observable and descriptive `pass@k` (Chen et al., 2021) can be calculated for k > 1, but independence assumptions remain unverified.

## Prompt

Each sample was generated from the task's own `meta.json` (`entry_point`,
`description`) and `tests/test_solution.py`, under the following controlled
instruction (the task's description and required function name were supplied from
the task metadata):

```
Implement a single top-level Python function named exactly <entry_point> that
solves the following task. Use the Python standard library only. Write it in the
style of a capable AI coding assistant: a clear function with type hints, a
concise docstring, and light defensive checks; correct and readable. Handle the
edge cases implied by the task. Return only a module that defines the function,
with no top-level executable statements, no input/print, and no __main__ block.

Task: <description>
```

## Predecessor (hand-authored reference)

The earlier hand-authored, LLM-*styled* solution for each task (used during
development before real model output was available) is retained for transparency
at `dataset/tasks/<task_id>/solutions/llm_curated_reference.py`. It is **not**
read by the pipeline; the analysis uses only the archived model-labelled samples under
`solutions/llm/`.

## Optional re-generation

`src/regenerate_llm.py` can regenerate the LLM arm from a live API if a future
user sets `LLM_API_KEY` (off by default; the core pipeline never needs it). Doing
so makes that run non-deterministic until the new files are committed.


## Independent verification limitations (2026-10-15 review)

The archived statement above says task test files were available during generation.
Therefore the main study's 100% model pass rate measures correctness on
**generation-visible tests**, and must not be presented as unseen-test accuracy.
No original signed provider response, response ID, timestamped transaction log,
or independent evidence authenticating the exact model identifier and settings
was supplied in the archive. Model identity, date, and independence remain
**author-reported, not independently verified**. Variability in stored samples
alone does not prove independent decoding events.

Do not alter historical dates/IDs or invent API parameters. If genuine provider
receipts, records or Git history exist, archive the originals and describe
which claims they substantiate.
